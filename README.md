## 🚀 SECOND STEP


### Installation
1. Clone the repository
   ```sh
   git clone [https://github.com/](https://github.com/)[YOUR_USERNAME]/[YOUR_REPOSITORY].git
   ```
2. Navigate into the project directory
   ```sh
   cd [YOUR_REPOSITORY]
   ```
3. Install dependencies
   ```sh
   npm install
   ```
